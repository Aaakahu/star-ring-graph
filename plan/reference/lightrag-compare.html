输入关键词 → 选学习动作 → 命中卡片在星环上发光 + 答案 + 侧栏分组列出。
GLM-5.2 答案
数列极限的求解常用 ε-N 定义法：对任意 ε>0 找 N 使 n>N 时 |xₙ-a|<ε。技巧上，夹逼准则放缩上下界、单调有界定理证收敛，是两条主力路径。反例（如 sin n 有界但不收敛）用于排除。
命中实体 → 映射到星环节点 3 个
集成价值：① 问问题拿答案（不用翻笔记）② 命中节点发光脉冲，一眼看见相关知识在哪 ③ 未命中暗化，焦点清晰 ④ 侧栏列出每个实体对应的原笔记，点击可跳转 ⑤ 跨章节关联（如"夹逼准则"在极限和级数都出现）自动浮现。
演示用 mock 数据，未真实调用 LightRAG。
4 个动作 = 4 个考研复习场景，切动作 + 切结构优化开关看命中差异：
• 输入 泰勒展开 + 📖学概念 → 只亮 MOC + 是什么 Flash
• 输入 极限怎么求 + 🛠找方法 → 只亮怎么做 Flash（know_how），过滤掉定义和错题
• 输入 泰勒展开 + ⚠查错题 → 亮 Error 卡 + 反查它暴露的 Flash 套路盲点
• 输入 数列极限 + 📚复习专题 → MOC + 全部 Flash + 全部错题一次性亮
关掉结构优化对比：纯 LightRAG 把所有卡片当平权文本，4 个动作结果几乎一样 —— 这就是不优化的代价。
