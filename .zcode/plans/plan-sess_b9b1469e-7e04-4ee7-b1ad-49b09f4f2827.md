# 查询星云节点少时改用力导向聚拢布局

## 背景与数据验证
查询星云（starNebulaClusterLayout）的节点规模实测：6-20 个（search limit=20 封顶）。
- 多数查询（渐近线 7、微分方程 6、极值 15）≤15 个节点
- 高频词（泰勒/极限 20 个）=20 个

当前算法对 6-15 个节点过重：连通分量分解 + 每星团跑 starRingSectorLayout（径向/旭日图）+ 圆周分布 + 碰撞分离。节点少时多数是单星团，退化为"小旭日图"，节点散在环上，不够聚拢。

## 决策（用户确认）
- **≤15 节点**：用力导向聚拢（自然聚拢中央，标签靠 resolveLabelOverlaps 避让）
- **>15 节点**：保留 starNebulaClusterLayout（星团避障）
- 阈值 15 基于实测数据

## 架构约束（探索确认）
1. **手动算坐标**：现有所有布局函数（starRingSectorLayout / fishboneLayout / starNebulaClusterLayout）都是手动算 x/y 写到节点上，G6 不配 layout（L1170 注释）。新函数必须遵循同一模式。
2. **resolveLabelOverlaps 依赖 `_midAngle`**（L516）：标签避让靠从圆心到节点的角度决定标签朝向。新布局必须给每个节点设 `_midAngle = atan2(y, x)`。
3. **边的来源**：cropG6DataByQueryHits 返回"两端都命中"的原始边（tree + aux）。弹簧力从这些边来。
4. **坐标尺度**：现有 baseR 120-280。聚拢场景用更紧凑的理想距离（60-100px），让节点自然聚拢。
5. **入口点**：L1079-1082 的 `if (opts?.prebuiltG6Data)` 分支，starNebulaClusterLayout 调用处。

## 改动：新增 forceClusterLayout 函数 + starNebulaLayout 入口分流

### 新函数 `forceClusterLayout`（view.ts，放在 starNebulaClusterLayout 之后）

简易力导向：排斥力 + 弹簧力 + 中心引力，迭代收敛。

```typescript
// 力导向聚拢布局：节点少（≤15）时用。自然聚拢中央，有连接的靠近、无连接的略分开。
// 手动算坐标（和 starRingSectorLayout 同模式），算完设 _midAngle 供 resolveLabelOverlaps 用。
function forceClusterLayout(nodes: any[], edges: any[]) {
  const hitNodes = nodes.filter(n => n.id !== '__query_root__' && n._queryRank !== undefined || n.level !== 0);
  if (hitNodes.length === 0) return;

  // rank=0（最相关）居中，其余在小圆上初始化（避免全堆原点）
  const byRank = [...hitNodes].sort((a, b) => (a._queryRank ?? 999) - (b._queryRank ?? 999));
  byRank[0].x = 0; byRank[0].y = 0;
  const initR = 70;
  for (let i = 1; i < byRank.length; i++) {
    const a = (2 * Math.PI) * (i / (byRank.length - 1));
    byRank[i].x = Math.cos(a) * initR;
    byRank[i].y = Math.sin(a) * initR;
  }

  // 邻接表（弹簧力来源）
  const adj = new Map<string, Set<string>>();
  hitNodes.forEach(n => adj.set(n.id, new Set()));
  edges.forEach(e => {
    adj.get(e.source)?.add(e.target);
    adj.get(e.target)?.add(e.source);
  });

  // 力导向参数
  const REPULSION = 8000;      // 排斥力强度（节点对，距离平方反比）
  const IDEAL_DIST = 80;       // 弹簧理想距离（有边连接的节点拉近到此距离）
  const SPRING_K = 0.15;       // 弹簧刚度
  const CENTER_PULL = 0.02;    // 中心引力（轻微拉向原点，防止扩散）
  const DAMPING = 0.85;        // 阻尼（防止振荡）
  const ITER = 60;             // 迭代次数（60 轮足够收敛）

  const vel = new Map<string, { x: number; y: number }>();
  hitNodes.forEach(n => vel.set(n.id, { x: 0, y: 0 }));

  for (let iter = 0; iter < ITER; iter++) {
    const force = new Map<string, { x: number; y: number }>();
    hitNodes.forEach(n => force.set(n.id, { x: 0, y: 0 }));

    // 排斥力（节点对）
    for (let i = 0; i < hitNodes.length; i++) {
      for (let j = i + 1; j < hitNodes.length; j++) {
        const a = hitNodes[i], b = hitNodes[j];
        let dx = (b.x || 0) - (a.x || 0), dy = (b.y || 0) - (a.y || 0);
        let dist = Math.hypot(dx, dy) || 0.01;
        const rep = REPULSION / (dist * dist);
        const ux = dx / dist, uy = dy / dist;
        force.get(a.id)!.x -= ux * rep;
        force.get(a.id)!.y -= uy * rep;
        force.get(b.id)!.x += ux * rep;
        force.get(b.id)!.y += uy * rep;
      }
    }

    // 弹簧力（有边连接的节点）
    edges.forEach(e => {
      const a = hitNodes.find(n => n.id === e.source);
      const b = hitNodes.find(n => n.id === e.target);
      if (!a || !b) return;
      const dx = (b.x || 0) - (a.x || 0), dy = (b.y || 0) - (a.y || 0);
      const dist = Math.hypot(dx, dy) || 0.01;
      const disp = dist - IDEAL_DIST;
      const ux = dx / dist, uy = dy / dist;
      const f = SPRING_K * disp;
      force.get(a.id)!.x += ux * f;
      force.get(a.id)!.y += uy * f;
      force.get(b.id)!.x -= ux * f;
      force.get(b.id)!.y -= uy * f;
    });

    // 中心引力 + 应用力 + 阻尼
    hitNodes.forEach(n => {
      const f = force.get(n.id)!;
      f.x -= (n.x || 0) * CENTER_PULL;
      f.y -= (n.y || 0) * CENTER_PULL;
      const v = vel.get(n.id)!;
      v.x = (v.x + f.x) * DAMPING;
      v.y = (v.y + f.y) * DAMPING;
      n.x = (n.x || 0) + v.x;
      n.y = (n.y || 0) + v.y;
    });
  }

  // 设 _midAngle（resolveLabelOverlaps 依赖它决定标签朝向）
  hitNodes.forEach(n => {
    n._midAngle = Math.atan2(n.y || 0, n.x || 0);
  });
}
```

**参数设计理由**：
- REPULSION 8000：节点对距离 80px 时排斥力 ≈ 8000/6400 = 1.25，和弹簧力 SPRING_K*disp = 0.15*0 = 0 平衡（IDEAL_DIST=80 时弹簧力为 0）。排斥力防止重叠。
- IDEAL_DIST 80：比全局 baseR 120 紧凑，节点自然聚拢。
- CENTER_PULL 0.02：轻微引力防止扩散，但不至于全堆原点。
- ITER 60：15 个节点 O(n²) = 225 对/轮 × 60 = 13500 次计算，毫秒级。
- DAMPING 0.85：标准值，防止振荡。

## 风险与回退
- **风险**：力导向参数（REPULSION/IDEAL_DIST/CENTER_PULL）可能需要微调。60 轮迭代对 15 节点是 O(n²)=225 对/轮，性能无忧，但视觉效果（紧凑度、是否振荡）需实测。
- **回退**：删 forceClusterLayout + 去掉入口分流，恢复原逻辑。改动集中在新增函数 + 3 行分流判断。
- **参数旋钮**：如果聚拢效果不理想，三个主旋钮：
  - 太散 → IDEAL_DIST 调小（80→60）或 CENTER_PULL 调大（0.02→0.05）
  - 太挤 → REPULSION 调大（8000→12000）
  - 振荡 → DAMPING 调小（0.85→0.8）或 ITER 调大（60→100）
